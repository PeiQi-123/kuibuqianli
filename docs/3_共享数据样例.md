# 跬步千里 - 共享数据样例

## 一、数据类型概述

本系统涉及的主要共享数据类型包括：

| 数据类型 | 说明 | 存储位置 | 数据量估算 |
|----------|------|----------|------------|
| 高清视频 | 微运动教学视频 | 文件系统/对象存储 | 每个视频约10-50MB |
| 3D模型 | 人体部位选择3D模型 | 前端assets | 每个模型约2-5MB |
| 用户数据 | 用户基本信息、偏好 | MySQL | 每条记录约1KB |
| 运动记录 | 运动历史记录 | MySQL | 每条记录约2KB |
| 推荐追踪 | 推荐算法中间数据 | MySQL | 每条记录约5KB |
| 健康数据 | 设备健康监测数据 | MySQL/设备SDK | 每分钟约100Bytes |
| 视频元数据 | 视频属性信息 | MySQL | 每条记录约1KB |

## 二、高清视频数据样例

### 2.1 视频文件规格

| 属性 | 规格 |
|------|------|
| 格式 | MP4 (H.264编码) |
| 分辨率 | 1080p (1920x1080) |
| 帧率 | 30fps |
| 码率 | 约2-4 Mbps |
| 时长 | 30-120秒 |
| 文件大小 | 约10-50MB |

## 三、3D模型数据样例

### 3.1 模型规格

| 属性 | 规格 |
|------|------|
| 格式 | GLB (GL Transmission Format Binary) |
| 面数 | 约5000-10000面 |
| 纹理 | PBR材质 |
| 文件大小 | 约2-5MB |

### 3.2 模型文件列表

| 文件名 | 说明 | 大小 |
|--------|------|------|
| human_body.glb | 标准人体模型 | 3.2MB |
| human_body_clean.glb | 简化人体模型 | 2.1MB |
| human_body_blue_clean.glb | 蓝色主题人体模型 | 2.3MB |
