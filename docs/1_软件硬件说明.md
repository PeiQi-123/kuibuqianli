# 跬步千里 - 软件与硬件说明

## 一、系统概述

"跬步千里"是一个面向久坐人群的微运动健康管理系统，采用前后端分离架构，通过智能推荐算法为用户提供个性化微运动方案。

## 二、硬件需求

### 2.1 服务器端硬件

| 组件 | 最低配置 | 推荐配置 | 说明 |
|------|----------|----------|------|
| CPU | 4核 | 8核及以上 | 处理推荐算法和并发请求 |
| 内存 | 8GB | 16GB及以上 | 支持Java应用和数据库缓存 |
| 存储 | 50GB SSD | 100GB SSD及以上 | 存储视频文件和数据库数据 |
| 网络 | 100Mbps | 1Gbps | 支持视频流传输和API响应 |

### 2.2 客户端硬件

#### 移动设备（Android/iOS）
| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|

| CPU | 八核1.8GHz | 八核2.0GHz及以上 |
| 内存 | 3GB | 4GB及以上 |

| 传感器 | 加速度计、陀螺仪 | 加速度计、陀螺仪、磁力计 |

#### 桌面设备（Windows/macOS/Linux）
| 组件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| 操作系统 | Windows 10 / macOS 10.15 / Ubuntu 20.04 | Windows 11 / macOS 12.0+ / Ubuntu 22.04+ |
| CPU | 双核2.0GHz | 四核2.5GHz及以上 |
| 内存 | 4GB | 8GB及以上 |
| 存储 | 20GB可用空间 | 50GB及以上可用空间 |

#### Web端
| 组件 | 要求 |
|------|------|
| 浏览器 | Chrome 80+, Firefox 75+, Safari 13+, Edge 80+ |

### 2.3 可选硬件设备

#### OPPO健康手表/手环
- 支持设备：OPPO Watch系列、OPPO Band系列
- 功能：心率监测、步数统计、睡眠监测、久坐提醒
- 连接方式：蓝牙BLE

#### 智能摄像头
- 分辨率：1080p及以上
- 帧率：30fps及以上
- 用途：姿态检测、动作识别

## 三、软件环境

### 3.1 服务器端软件

#### 操作系统
- 推荐：Ubuntu 22.04 LTS / CentOS 8+
- 兼容：Windows Server 2019+ / macOS Server

#### 数据库
- **MySQL 8.0+**
  - 字符集：utf8mb4
  - 排序规则：utf8mb4_unicode_ci
  - 用途：用户数据、运动记录、推荐日志等结构化数据存储

#### 后端运行环境
- **JDK 17+**
  - OpenJDK 17 / Oracle JDK 17
- **Maven 3.6+**
  - 用于项目构建和依赖管理

#### AI服务运行环境
- **Python 3.8+**
- **FastAPI 0.104+**
- **Uvicorn 0.24+**

#### Web服务器/反向代理
- **Nginx 1.18+**
  - 用途：静态资源服务、反向代理、负载均衡

#### 容器化（可选）
- **Docker 20.10+**
- **Docker Compose 2.0+**

## 四、网络架构

### 4.1 部署架构

```
                    ┌─────────────┐
                    │   用户端     │
                    │ (多平台)     │
                    └──────┬──────┘
                           │ HTTPS
                    ┌──────▼──────┐
                    │   Nginx     │
                    │  反向代理    │
                    └──┬──────┬───┘
                       │      │
           ┌───────────┘      └───────────┐
           │                              │
    ┌──────▼──────┐                ┌─────▼──────┐
    │  Spring Boot│                │  静态资源   │
    │   后端服务   │                │  (视频等)   │
    └──────┬──────┘                └────────────┘
           │
    ┌──────▼──────┐
    │   MySQL     │
    │   数据库     │
    └─────────────┘
           │
    ┌──────▼──────┐
    │  FastAPI    │
    │  AI服务     │
    └──────┬──────┘
           │
    ┌──────▼──────┐
    │ DeepSeek API│
    └─────────────┘
```

### 4.2 端口配置

| 服务 | 默认端口 | 说明 |
|------|----------|------|
| Spring Boot后端 | 8080 | API服务端口 |
| FastAPI AI服务 | 8000 | AI服务端口 |
| MySQL | 3306 | 数据库端口 |
| Nginx | 80/443 | HTTP/HTTPS端口 |
