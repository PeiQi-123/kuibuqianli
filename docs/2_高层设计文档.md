# 跬步千里 - 高层设计文档(High Level Design Document)

## 一、设计概述

### 1.1 系统目标

"跬步千里"微运动健康管理系统的核心目标是：
- 为久坐人群提供科学、安全、个性化的微运动方案
- 通过智能推荐算法，实现"千人千面"的运动推荐
- 建立完整的"提醒-推荐-跟练-反馈-学习"闭环
- 利用AI技术提升推荐精准度和用户体验

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 模块化设计 | 各功能模块高内聚、低耦合，便于独立开发和维护 |
| 可扩展性 | 支持新功能、新算法、新设备的快速接入 |
| 安全性 | 用户数据加密存储，API接口鉴权保护 |
| 可用性 | 支持多平台，提供友好的用户交互体验 |
| 可观测性 | 完整的日志记录、推荐追踪和性能监控 |

## 三、关键设计决策

### 3.1 两阶段推荐架构

**决策：** 采用"候选召回 + LLM重排"的两阶段推荐架构，而非单阶段LLM直接生成。

**理由：**
1. 可控性：确保推荐动作在已有视频库范围内
2. 可解释性：清晰区分召回分和重排分
3. 可优化：支持离线分析和A/B测试
4. 成本：降低LLM Token消耗

**参考：** Twitter开源推荐算法、ByteDance Monolith架构思想

### 3.2 推荐追踪数据持久化

**决策：** 创建`recommendation_trace`表，保存推荐全流程中间结果。

**理由：**
1. 可诊断：排查推荐结果的产生原因
2. 可优化：支持离线评估和算法迭代
3. 可解释：为用户提供推荐理由
4. 可追溯：完整记录推荐链路

### 3.3 多平台前端统一

**决策：** 使用Flutter实现多平台（Android/iOS/Web/Windows/macOS/Linux）统一前端。

**理由：**
1. 开发效率：一套代码多平台运行
2. 用户体验：一致的UI和交互
3. 维护成本：降低多团队维护开销

### 3.4 JWT无状态认证

**决策：** 采用JWT（JSON Web Token）实现无状态认证。

**理由：**
1. 可扩展：支持分布式部署
2. 性能：减少数据库查询
3. 移动端友好：适合App场景

## 四、数据库设计概要

### 4.1 核心数据表

| 表名 | 用途 | 关键字段 |
|------|------|----------|
| user | 用户基本信息 | id, username, password, height, weight, bmi, age, gender |
| user_preference | 用户偏好配置 | user_id, preference_key, preference_value |
| exercise_record | 运动记录 | user_id, motion_name, duration, completed, feedback_tag, feedback_score |
| recommendation_trace | 推荐追踪明细 | exercise_record_id, action_name, recall_score, llm_rerank_score, final_score, selected |
| video | 视频信息 | id, title, file_path, duration, file_size |
| video_attribute | 视频属性 | video_id, attribute_type, attribute_value |
| remind_log | 提醒日志 | user_id, actual_time, status |

## 五、接口设计概要

### 5.1 RESTful API设计原则

- 资源命名：使用名词复数形式
- HTTP方法：GET（查询）、POST（创建）、PUT（更新）、DELETE（删除）
- 状态码：200（成功）、201（创建）、400（请求错误）、401（未认证）、403（无权限）、500（服务器错误）
- 统一响应格式：`Result<T>` 包装

### 5.2 核心API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/user/register | POST | 用户注册 |
| /api/user/login | POST | 用户登录 |
| /api/user/profile | GET/PUT | 获取/更新用户信息 |
| /api/micro-motion/generate-prompt | POST | 生成微运动推荐 |
| /api/motion/record | POST | 保存运动记录 |
| /api/motion/feedback | POST | 提交运动反馈 |
| /api/reminder/status | GET/PUT | 获取/更新提醒状态 |
| /api/reminder/log | POST | 记录提醒日志 |
| /api/health/data | GET | 获取健康数据汇总 |
| /api/video/{id} | GET | 获取视频信息 |
| /api/video/list | GET | 获取视频列表 |
